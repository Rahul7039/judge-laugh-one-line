A one-line joke for make.fun's "Make the Judge Laugh in One Line" bounty. The joke lands in three beats inside a single line: the AI assistant charges for the thinking, apologises for the punchline, and then bills the silence as a feature — a deadpan take on pay-per-token AI pricing that anyone who has watched a meter run while waiting for an answer will recognise. The program is deliberately minimal: standard library only, deterministic, it prints the line to stdout and writes the identical line to `/output/entry.txt` for the program/v1 harness.

## Run it

```sh
python3 main.py
```
